# Test Matrix — Multi-format ingestion (WI-1 … WI-12)

Plan: `.claude/tdd-guardian/plan-20260730-163558.md`

Runner: `python3 -m unittest discover -s tests`. Every case below is a `unittest.TestCase` method. Default suite must pass with **zero optional backends**. Assertion levels cite `policy-core`: **L1** return-value · **L2** side-effect read-back (`.txt` / `PROVENANCE.jsonl` / filesystem) · **L3** real end-to-end through `ingest()` / `cli.main()` · **L4** state · **L5** mock only the lazy-import/subprocess boundary, then assert observable output. No case relies solely on L6-7.

## Shared fixture builders (real stdlib, never mocked)

These are helpers the matrix references by name; each is built with real `zipfile`/`hashlib`/`io.BytesIO` — no backend.

- `make_epub(spine_order, chapters, *, mimetype="application/epub+zip", drop_mimetype=False) -> bytes` — `zipfile.ZipFile(buf,"w")`: first entry `mimetype` written **stored+uncompressed** (`ZIP_STORED`); `META-INF/container.xml` → `OEBPS/content.opf`; OPF `<manifest>` lists `c1.xhtml/c2.xhtml/c3.xhtml/nav.xhtml`, `<spine>` `itemref`s in `spine_order`; chapters written to the zip in storage order c1,c2,c3, each carrying a unique marker (`MARK_A`/`MARK_B`/`MARK_G`). Spine order `[c3,c1,c2]` differs from both alphabetical (c1<c2<c3) and storage (c1,c2,c3).
- `make_docx(paragraphs) -> bytes` — `[Content_Types].xml` + `word/document.xml` with default `xmlns:w="http://schemas.openxmlformats.org/wordprocessingml/2006/main"`, namespaced `<w:p>/<w:r>/<w:t>` (and `<w:br/>`, `<w:tab/>`, empty `<w:p/>` as needed).
- `zip_declared_oversize(cap) -> bytes` — one member `b"A"*(cap+1)` via `writestr`; honest `ZipInfo.file_size == cap+1` (drives the *pre-decompress* declared-size guard).
- `zip_lying_header(cap) -> bytes` — a deflate member whose central-directory `uncompressed_size` field is patched (raw-byte edit) to a value **under** `cap`, while the real inflate stream expands **past** `cap` (drives the *cumulative real-byte* streaming guard; kills a header-only check).
- `zip_traversal(names=("../evil.xhtml","/etc/lode_evil"))` — entries with `..`/absolute names plus a valid `mimetype`/`word/document.xml` so sniff passes and the traversal guard is the thing that fires.
- Wrong-extension: reuse `make_epub()` bytes on disk as `book.docx`; `make_docx()` bytes as `doc.epub`; `b"%PDF-1.7\n..."` as `foo.txt`.

Frozen `Config` means dict-path variation uses `dataclasses.replace(cfg, dict_path=...)` or a `[normalize] dict_path` in `library.toml`. PDF backends are mocked at `lode.lib.formats.pdf.subprocess.run` (for `_pdftotext`) or by patching the module symbols `lode.lib.formats.pdf._xberg` / `._docling` (the lazy-import seam). Each mocked path is paired with a `@unittest.skipUnless(importlib.util.find_spec(...))` real integration test.
